# Sales & Orders Performance Analysis

## Overview
This repository contains an interactive Excel dashboard designed to analyze retail performance across key operational metrics. The dashboard synthesizes sales revenue, order volumes, geographic distributions, and product-level trends to support data-driven decision-making.

## Dashboard Features & Insights

* **Monthly Sales Trends:** Identifies monthly revenue fluctuations, highlighting revenue peaks (May at $8,659,916) and key seasonal shifts, such as the notable trend shift from October to December.
* **Geographic Analysis:** Evaluates order counts and product distribution across major regions including Alexandria, Aswan, Cairo, Giza, and Mansoura.
* **Category & Product Performance:** Breaks down distribution across categories (Books, Clothing, Electronics, Furniture, Toys) and tracks product-specific performance metrics across various SKUs.
* **Interactive Filtering:** Features dynamic slicers for Month, Order ID, Region, Quantity, Category, Product Name, and Sales ranges for granular data exploration.
